Under the hood

No server. No dependency on a signal that isn't coming back.

◇

Service Worker caching

Every lesson, quiz, and media asset is intercepted and cached on first load, so revisiting a page never touches the network again.

▤

LocalStorage persistence

Progress, quiz scores, and unlocked modules are written directly to the browser — nothing is lost when the device restarts or the tab closes.

⛁

Prerequisite gatekeeping

checkPrerequisite() enforces the CHED IT sequence in logic, not just in the UI — the next island simply doesn't open until it should.

▽

Cache API for media

Diagrams, narrated walkthroughs, and code demos are stored as cached responses — heavy media loads once, then plays instantly forever.

◫

Zero-cost architecture

HTML5, CSS3, and vanilla JavaScript only — no framework build step, no paid backend, nothing that breaks when funding does.

◔

Legacy hardware target

Tuned to run smoothly on the machines already sitting in classroom labs — not the newest devices, the ones that are actually there.
